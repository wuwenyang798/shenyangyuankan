# CPSC新规落地，你的货可能被扣在码头！

> **7月8日起，美国消费品监管从“抽查”变“必查”，没有电子申报连清关资格都没有**

“货已经到港了，报关行说缺一个CPSC数据，现在整柜被扣在码头，每天300美金滞港费。”这是最近一个月我在跨境群里看到频率最高的一句话。

6月还没过完，已经有一批卖家因为新规栽了跟头。7月8日才是真正的“大限”——所有受CPSC监管的进口消费品，必须在清关前完成电子申报，**没有例外、没有小额豁免**。

如果你还在犹豫“要不要做”，这篇文章会帮你彻底搞懂。


## 一、CPSC是什么？为什么要关注它？

### 📌 CPSC（美国消费品安全委员会）

美国联邦政府独立监管机构，成立于1972年，负责监管超过15,000种消费品的**安全性**。从儿童玩具到成人服装，从家具到电子电器，只要是在美国市场上销售的消费品，几乎都在它的管辖范围内。

**它的权力有多大？** 有权强制召回产品、禁止进口、开出巨额罚单，甚至可以起诉违规企业。

### 📌 四个高频术语，一次分清

| 术语 | 全称 | 是什么 | 谁负责 |
| --- | --- | --- | --- |
| **CPSC** | 美国消费品安全委员会 | 监管机构 | 美国政府 |
| **CPC** | 儿童产品证书 | 12岁以下儿童产品的**纸质证书** | 进口商/制造商出具 |
| **GCC** | 通用合格证书 | 成人消费品的**纸质证书** | 进口商/制造商出具 |
| **CPSP/eFiling** | 消费品安全电子申报 | 本次新规核心——**电子化申报** | 进口商通过报关行申报 |

> **一句话总结**：CPSC是管事的机构，CPC/GCC是纸质的证书，eFiling是把证书数据**提前在网上提交**的新流程。


## 二、新规核心：从“事后抽查”到“事前拦截”

### 🔥 旧规 vs 新规，一张表看懂变化

| 对比维度 | 旧规（7月8日前） | 新规（7月8日起） |
| --- | --- | --- |
| **申报方式** | 纸质证书，海关抽查时才出示 | **强制电子申报**，清关前必须完成 |
| **监管逻辑** | 事后抽查 | **事前合规准入** |
| **申报入口** | 无统一系统 | 必须通过**ACE海关系统**提交 |
| **低价豁免** | 800美元以下免申报 | ❌ **无任何金额豁免** |

### 📋 三个关键时间节点

| 时间 | 事件 |
| --- | --- |
| **2026年7月8日** | 绝大多数直接进口消费品，**强制实施电子申报** |
| **2026年7月8日（同日）** | 美国本土制造产品同步更新证书内容要求 |
| **2027年1月8日** | 经**自由贸易区（FTZ）** 进口的消费品，缓冲期截止 |

> ⚠️ **特别注意**：生效时间以**货物到港日期**为准。6月发货但7月8日后到港的，同样需要完成电子申报，**没有任何侥幸空间**。

### 🎯 新规的目的是什么？

CPSC官方给出的解释是——通过电子化申报，让海关在货物到港前就能识别高风险产品，**把不合规的货拦在岸上，而不是等流入市场后再召回**。

但跨境圈里还有另一种解读：**这是美国制造业回流战略的一部分**。电子申报只针对进口产品，美国本土制造不受此限。叠加T86免税取消，美国正在用“合规门槛”系统性抬高跨境小包的进入成本。


## 三、哪些产品必须申报？附完整清单

### 📦 核心原则

**所有受CPSC监管的进口消费品，全部强制电子申报**。

判断标准：如果产品需要**CPC**或**GCC**证书，就必须进行eFiling申报。

### 🎯 涉及产品清单

| 品类 | 具体产品举例 | 适用证书 |
| --- | --- | --- |
| 👶 **12岁及以下儿童产品** | 玩具、童装、儿童首饰、婴儿床、安抚奶嘴、儿童推车、儿童安全座椅 | **CPC**（必须CPSC认可实验室检测） |
| 👕 **纺织服饰** | 服装、内衣、泳衣、帽子、围巾、窗帘、床品 | **GCC**（成人服装部分面料免测） |
| 🪑 **家具家居** | 床垫、沙发、桌椅、地毯、地垫、蜡烛 | **GCC** |
| 🔌 **消费电子与电池** | 充电器、电源适配器、锂电池、充电宝、**纽扣电池及含纽扣电池产品** | **GCC** |
| 🛠️ **工具与防护设备** | 电动工具、割草机、安全梯子、骑行头盔、打火机 | **GCC** |

### 🔍 如何自查产品是否需要申报？

登录CPSC官网eFiling页面（cpsc.gov/eFiling），使用内置 **“Regulatory Robot”工具**，输入产品名称、材质、用途，一键判定是否需要电子申报。这是目前最准确、最权威的核查方式。

### ⚠️ 哪些产品**不需要**申报？

- 不受CPSC安全规则约束的产品
- 零部件（非成品）
- **非商业用途**的个人礼品、私人物品
- 车辆、食品、药品、化妆品、医疗器械等由其他联邦部门监管的品类


## 四、如何完成合规申报？两种模式可选

### 📋 申报必备7项核心数据

无论选择哪种模式，以下7项数据缺一不可，且必须与CPC/GCC证书**完全一致**：

| 序号 | 数据要素 | 说明 |
| --- | --- | --- |
| 1 | **产品标识** | SKU、UPC、型号等唯一识别码 |
| 2 | **法规引用代码** | 产品符合的CPSC安全标准编号（如ASTM F963、16 CFR） |
| 3 | **制造日期与地点** | 生产年月+工厂完整名称地址 |
| 4 | **产品测试日期** | 最近一次合规检测的年月 |
| 5 | **测试实验室信息** | **CPSC认可实验室**的名称、地址、联系方式 |
| 6 | **进口商联系方式** | 美国IOR（登记进口商）完整信息 |
| 7 | **记录保管联系人** | 负责保存测试记录的人员信息 |

### 🔑 核心红线：三主体必须一致

**CPC/GCC证书上的进口商 = 电子申报的注册主体 = ACE清关的IOR抬头**

三者公司名称、地址必须**100%匹配**。否则系统直接预警、触发查验。

### 🛤️ 两种申报模式对比

| 对比维度 | 模式一：完整申报 | 模式二：引用申报 |
| --- | --- | --- |
| **操作方式** | 每票报关提交全部7项数据 | 提前在CPSC产品库备案，后续仅提交证书ID |
| **前期准备** | 无需注册，零备案 | 需注册CPSC企业账号，录入所有SKU |
| **适合卖家** | SKU少、出货零散的中小卖家 | **多SKU、大批量补货的FBA卖家** |
| **长期效率** | 低，每票重复录入 | 高，一次录入永久复用 |


## 五、不合规的五大后果

| 后果 | 具体影响 |
| --- | --- |
| 1️⃣ **清关被扣** | 未申报或数据不符，货物直接被系统拦截，无法放行 |
| 2️⃣ **额外费用** | 滞港费、柜租、查验费——少则数百、多则数千美元 |
| 3️⃣ **高额罚款** | 每项违规最高可罚约**12万美元** |
| 4️⃣ **退运/销毁** | 严重不合规的货物被强制退运或销毁 |
| 5️⃣ **进黑名单** | IOR被标记高风险，后续所有货物持续严查 |
