> **6月29日起，亚马逊对自发货卖家“动手”了——你填的发货时间，必须和实际完全一致**

做自发货的卖家都清楚一个“潜规则”：明明1天就能发货，偏要在后台填2-3天。给自己留足缓冲，防止爆单或断供时手忙脚乱，还能给提前收到货的买家制造“物流极速”的惊喜感。

但2026年6月29日起，这套玩了多年的玩法，彻底终结了。


## 一、新规核心：发货太快也不行

亚马逊发现，美国站超过87%的自发货订单实际上都能在1天内处理完毕，但大量卖家为了规避延迟发货率超标的风险，刻意在后台设置较长的处理时间。

数据很直白：**送达承诺每提前一天，前端销量大约能拉升5%**。你为了自己稳妥把时间设长，前台显示的送达日期极其靠后，直接劝退了大量潜在买家。

**新规的核心就一句话：真实发货速度必须和后台填写的发货时效完全一致**。

**两个关键时间节点**：

| 时间节点 | 核心动作 |
| --- | --- |
| **2026年6月29日** | 新规正式生效，每个自配送SKU的备货时间必须与实际发货速度一致，误差不得超过1天 |
| **2026年9月1日** | 系统开始按30天滚动周期监控，发现设置值比实际表现多1天以上且持续超30天，**强制启用AHT** |

**不适用范围**：定制商品、手工艺品、重型大件（150磅以上）可暂不适用。


## 二、SFP配送速度指标同步升级（7月6日生效）

如果你在使用Seller Fulfilled Prime（SFP），7月6日起配送速度指标也将全面收紧：

| 商品类型 | 指标 | 旧标准 | 新标准 |
| --- | --- | --- | --- |
| **标准件** | 1日达浏览量占比 | 30% | **40%** |
| | 2日达浏览量占比 | 70% | **75%** |
| | 5日达浏览量占比 | — | **90%** |
| **大件** | 1日达浏览量占比 | 10% | **15%** |
| | 5日达浏览量占比 | 70% | **80%** |
| **超大件** | 2日达浏览量占比 | 15% | **25%** |
| | 5日达浏览量占比 | 50% | **60%** |

如果商品已达标，无需任何操作。

> ⏰ **过渡期保护**：2026年10月17日前，周末不计入SFP速度指标考核，但过渡期内仍需按SFP绩效要求在周末正常履约。


## 三、卖家避坑指南：三条路怎么选？

### 🚀 方案一（强烈推荐）：启用自动备货时间（AHT）

这是官方最主推的方案。系统根据你近30天的真实发货历史，自动为每个SKU匹配处理时间。

**最大的诱惑**：启用AHT后，**即便迟发率不满足绩效要求，也不会因此被停售自配送商品**。

**操作步骤**：卖家平台 → 〖设置〗→ 〖配送设置〗→ 〖一般配送设置〗→ 〖备货时间〗→ 〖编辑〗→ 选择〖自动设置备货时间〗→ 〖保存〗

> ⚠️ 注意：24小时内只能启用一次，更改最长需24小时生效。

**适合谁**：单量庞大、发货流程稳定的成熟团队。

### 📝 方案二：继续手动设置

如果你不想被系统接管，可以继续手动填。但头顶将悬着一把剑——系统按30天周期死死盯着你，只要实际发得比填的快，就会被抓出来警告。

**前提**：必须把之前虚高的缓冲天数挤干水分，填上最真实的数据。每个SKU的设置值与实际发货速度差值必须小于1天。

**适合谁**：发货速度波动较大、或带有轻度定制环节的卖家。

### 💀 方案三：什么都不做

如果到6月29日还不操作，亚马逊会**直接默认接管你所有SKU的处理时间**。更扎心的是——亚马逊的自动化系统会看你过去90天的发货记录，把承诺送达日期设定在**最理想的情况**，而不是你的平均水平。

这意味着，**你的缓冲期将彻底归零**。稍有差池，迟发率直线飙升，面临限制销售甚至封号的风险。


## 四、新手卖家现在该做什么？

| 优先级 | 行动项 | 截止时间 |
| --- | --- | --- |
| 🔴 **紧急** | 检查所有FBM SKU的备货时间设置，剔除虚高缓冲 | **6月29日前** |
| 🟠 **强烈建议** | 启用AHT自动备货时间，获得LSR保护 | 越早越好 |
| 🟡 **SFP卖家** | 评估1日达/2日达浏览量占比，提前优化 | **7月6日前** |
| 🟢 **提前关注** | 关注9月“自定义配送设置”新工具上线 | 9月 |

亚马逊正在开发一项新工具“自定义您的配送设置”（预计2026年9月上线），允许你按配送邮编分别设置出货时效、周末发货能力和截单时间。提前规划，到时候直接上手。


**写在最后**：

以前那种“低承诺高交付”的玩法，在2026年全面AI化的算法面前，已经彻底行不通了。平台要的是给买家**极致准确的预期**，而你要做的是**让后台数据匹配真实能力**。

发货太快被系统盯上，发货太慢被买家抛弃——这个平衡点，新规帮你找到了：**准确，就是最快的速度**。
