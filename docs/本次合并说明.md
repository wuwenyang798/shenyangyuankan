```bash

```

## Cloudflare 必须配置

1. 创建 Cloudflare D1 数据库。
2. 在 D1 SQL Console 执行：
   `migrations/0001_create_order_system.sql`
3. 在 Pages 项目中绑定 D1：
   - Variable name: `DB`
4. 添加环境变量：
   - `ADMIN_PASSWORD=你的后台密码`
   - `NODE_VERSION=20`

## 后台入口

部署完成后访问：

```txt
/admin
```

输入 `ADMIN_PASSWORD` 后即可查看、处理、导出询价订单。
