# 深洋远瞰询价接单系统部署说明

本升级包新增了一个可用的询价接单系统：用户在「价格获取」页面提交询价，数据进入 Cloudflare D1 数据库；你可以访问 `/admin` 查看订单、填写报价、更新状态和导出 CSV。

## 1. 新增功能

- 用户提交询价后写入 D1 数据库
- 后台页面：`/admin`
- 后台密码保护：通过环境变量 `ADMIN_PASSWORD`
- 订单状态：新询价、处理中、已报价、已成交、已关闭
- 支持搜索、筛选、保存报价、删除、导出 CSV

## 2. Cloudflare 中创建 D1 数据库

在 Cloudflare 后台进入：

`Workers & Pages -> D1 SQL Database -> Create database`

数据库名建议：

`shenyangyuankan-db`

## 3. 建表 SQL

打开你创建的 D1 数据库，进入 Console，把 `migrations/0001_create_order_system.sql` 的内容复制进去执行。

## 4. 绑定 D1 到 Pages 项目

进入你的 Pages 项目：

`Workers & Pages -> shenyangyuankan -> Settings -> Functions -> D1 database bindings`

添加绑定：

- Variable name：`DB`
- D1 database：选择 `shenyangyuankan-db`

注意：变量名必须是大写 `DB`。

## 5. 设置后台密码

进入 Pages 项目：

`Settings -> Environment variables`

添加：

- Variable name：`ADMIN_PASSWORD`
- Value：设置一个强密码，例如 `SyYK_2026_xxxxx`

同时保留：

- `NODE_VERSION = 20`

## 6. 上传代码并重新部署

把升级后的文件提交到 GitHub，Cloudflare Pages 会自动部署。

部署成功后访问：

- 用户提交页面：`/pricing`
- 后台接单页面：`/admin`

## 7. 后台使用方式

1. 打开 `/admin`
2. 输入 `ADMIN_PASSWORD`
3. 查看询价记录
4. 填写报价结果
5. 修改状态为「已报价」或「已成交」
6. 可点击导出下载 CSV

## 8. 安全建议

当前版本是 MVP 接单系统，后台 API 已用密码保护。正式运营时，建议再启用 Cloudflare Access 保护 `/admin` 路径，只允许你的邮箱访问。
